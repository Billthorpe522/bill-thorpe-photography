# Gottardo Family protected gallery

38 visible photographs from Crosswind Farms, Manhattan. Public four-photo covers are maintained separately and remain unchanged by this build. Authenticated thumbnails (up to 1200px), viewer images (up to 2560px), and unchanged full-size JPEG downloads use separate encrypted assets. Existing supplied photographs may retain their original encrypted bytes across all three endpoints. New variants have distinct AES-256-GCM AAD and fresh nonces. The existing gallery keys, password, cookie and rate limiter remain in use; no secret values are in this checkout. Each request is bounded by its exact encrypted byte count and a 32 MiB ceiling. ASSET_REF pins immutable assets.
